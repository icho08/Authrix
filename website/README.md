# Auth System Website

A Next.js authentication system with modern UI components.

## Getting Started

First, install dependencies:

```bash
pnpm install
```

Then, run the development server:

```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Features

- Authentication (Login/Register)
- Modern UI with Tailwind CSS
- Dark/Light theme support
- Responsive design
- TypeScript support

## Tech Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS
- Radix UI components
- Lucide React icons
